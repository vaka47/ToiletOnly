# UX Clarifications for Premium Direction

## 1) Onboarding clarity

- Explain the session mechanic before camera opens.
- Promise value fast: "unlock -> meet active people nearby now".
- Add a visible 3-step progress indicator.

## 2) Trust-first unlock UX

- When scan fails, show concrete fixes:
  - "Move back 30 cm",
  - "Increase lighting",
  - "Center full bowl and seat".
- Show confidence trend, not only binary result.

## 3) Keep logic transparency

- In chat and match cards, always show:
  - sessions left,
  - current keep state,
  - what happens next.

## 4) Safer moderation UX

- Report flow should feel protective, not punitive.
- Add a "what happens after report" explanation.
- Provide post-report reassurance state.

## 5) Premium perceived quality

- Reduce dense text blocks by 20-30%.
- Improve hierarchy with stronger H1/H2 contrast.
- Keep one dominant CTA per screen.

## 6) Investor demo constraints

- Every demo screen needs a clear "money shot" visual.
- Avoid edge-case branches during demo flow.
- Add deterministic prototype route for 5-minute pitch.
