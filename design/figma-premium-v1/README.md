# ToiletOnly Premium Design Pack (Figma v1)

This folder contains a premium redesign blueprint for ToiletOnly, prepared for direct execution in Figma.

## Goal

Create a venture-ready visual and UX layer that preserves the unique product mechanic (toilet-gated session access) while upgrading perceived quality, trust, and retention UX.

## Deliverables in this pack

- `tokens.json` - design tokens for colors, typography, spacing, radius, shadows, blur, and motion.
- `screens.md` - full screen inventory, layout specs, and interaction intent.
- `components.md` - reusable component system and variants.
- `microinteractions.md` - motion and haptic behavior for premium feel.
- `ux-clarifications.md` - UX decisions to reduce friction in onboarding and trust flows.
- `copy-premium-en.md` - premium English copywriting baseline.

## Figma file structure

Use the following page architecture:

1. `00 Cover`
2. `01 Foundations`
3. `02 Components`
4. `03 Patterns`
5. `04 Screens - Onboarding`
6. `05 Screens - Core Loop`
7. `06 Screens - Video`
8. `07 Screens - Safety & Trust`
9. `08 Screens - Empty / Edge States`
10. `09 Prototype Flows`

## Visual direction

- Brand tone: bold, elegant, sensual-tech.
- Contrast strategy: dark cinematic overlays + high-polish gradients.
- Material strategy: premium glass and soft depth, no noisy effects.
- Motion strategy: confident and controlled; no playful bounce spam.

## Success criteria

- A first-time user understands the unlock mechanic in under 8 seconds.
- Session state and trust state are always visible.
- Feed and video actions feel instant and high-confidence.
- Product can be presented to investors as a distinct premium social app, not a prototype.
